# 安全政策

## 支持范围

当前仅维护最新的 `main` 分支和最新发布版本。安全修复可能要求用户升级 Node.js 或 Ramify。

## 报告漏洞

请通过 GitHub 的[私密漏洞报告](https://github.com/yanglongyun/ramify/security/advisories/new)提交问题，不要公开披露未修复的漏洞。报告中请包含受影响版本、复现步骤、潜在影响和建议修复方式。维护者会尽快确认收到，并在评估后说明修复与披露计划。

## 运行边界

Ramify 默认监听 `0.0.0.0`，没有账户、远程认证或多用户权限模型。

- 只有画布节点缩略图使用空 `sandbox`，因此缩略图不执行 JavaScript。
- 右侧详情和独立窗口按完整网页运行，不添加 CSP 或 sandbox；作品可以执行脚本、加载外部资源、发起网络请求、提交表单和使用 Worker。
- 作品与 Ramify UI 同源，能够访问该来源下的页面和本地 API。
- 数据库、`artifacts/`、日志和运行状态保存在用户数据目录，可能包含用户提示词与作品内容；备份和清理必须把整个目录视为一个整体。
- Ramify 不需要 Agent API Key。请勿把密钥写入项目、作品或 Issue。
- 媒体可以引用浏览器支持的任意 URL；远程资源会向目标主机暴露用户的网络请求信息。
